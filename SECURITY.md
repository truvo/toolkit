# Security

## Report a vulnerability

Email [security@truvo.com](mailto:security@truvo.com). Don't report a security problem in a public issue or pull request.

Include:

- what you found, and where: a file in this repository, or the server at `https://api.truvo.com/v1/mcp`
- the steps to reproduce it
- what someone could do with it

The same address is in [truvo.com's security.txt](https://www.truvo.com/.well-known/security.txt).

## Scope

This repository holds configuration files and skills, with no code of its own. They connect your agent to one server, `https://api.truvo.com/v1/mcp`. Report problems with that server, the sign-in flow, or truvo.com to the same address.
